# 📡 Juniper AP12 Configuration Guide
This document describes the Juniper AP12 access point configuration used in this lab environment.
Due to Juniper licensing requirements, full CLI configuration is not provided, and screenshots are used instead.

---

# 🧰 Overview
**AP Model**
  - Juniper AP12

**Role in This Lab**
  - Provide wireless access for:
    - Enterprise WiFi (WPA2-Enterprise via RADIUS)
    - Guest WiFi (VLAN-based, captive portal handled by MikroTik)

**Authentication**
  - WPA2-Enterprise (802.1X)
  - RADIUS backend: MikroTik User Manager

---

# 🔐 Licensing Requirement
**⚠️ Important Notice**
To use Juniper AP12, an active Juniper Mist / Junos Space license is required.
Without a valid license:
  - AP cannot be fully managed
  - WLAN profiles cannot be deployed
  - RADIUS authentication will not function

This lab assumes:
  - A valid AP12 license is already applied
  - AP is adopted and managed via Juniper Mist

---

# 🌐 Network Integration
**Uplink Configuration**
  - AP12 is connected to Access Switch (C9300L)
  - Port operates as a 802.1Q trunk

### **VLAN Mapping**

| SSID           | VLAN      | Purpose         |
| -------------- | --------- | --------------- |
| WIRELESS-ENT   | VLAN 30   | WPA2-Enterprise |
| GUEST          | VLAN 20   | Captive portal  |

---

# 🔑 Authentication Flow
```Flow
Wireless Client
      ↓
Juniper AP12
      ↓
   MikroTik
      ↓
Accept / Reject
```
  - EAP methods:
    - PEAP
    - MSCHAPv2
